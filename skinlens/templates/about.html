關於 SkinLens

讓每個人用手機就能做的膚況檢測

醫美診所的 VISIA 膚質檢測要用專用拍攝箱和三種光源，一次要價數百元。SkinLens 用一般手機照片， 以影像處理找出 8 項膚況指標，告訴使用者問題在臉上哪裡、代表什麼、該怎麼保養，並讓會員追蹤保養前後的變化。

精準分區

MediaPipe 偵測臉部 478 個特徵點，依雙眼轉正、統一尺度後切成額頭、眼尾、臉頰等 10 個分區，指出問題的位置。

用人工標註校正

皺紋分數用 FFHQ-Wrinkle 資料集 1,000 張人工標註訓練校正模型，交叉驗證誤差比基準線低 23%；只有贏過基準線的模型才會上線。

追蹤與建議

每項指標依 5 級嚴重度給保養建議與就醫提醒；會員可看分數趨勢，任選兩次紀錄比較前後差異。

系統架構

前端 HTML / CSS / JavaScript + jQuery + Bootstrap 5，後端 Flask，資料庫 MongoDB。完整的 draw.io 原始檔在專案的 docs/architecture.drawio。

8 項指標與偵測方法

指標演算法
斑點L 通道黑帽運算找局部暗點，排除細長形
皺紋Frangi 脊線濾波 + 細長度篩選 + 模型校正
紋理高通濾波殘差的標準差
毛孔小核黑帽 + 面積 / 圓度篩選
棕色斑比周圍暗 + Lab b* (黃棕) 偏高
紅色區Lab a* 高於自己臉部中位數
紫外線色斑UV 照片中的暗斑
紫質UV 照片中 R 高、B 低的小亮點

隱私與限制

  • 沒登入、沒勾選同意時，照片分析完就丟棄，不會儲存
  • 會員的紀錄只有本人看得到，可以隨時在「帳號設定」一鍵刪除
  • 訓練資料只存匿名代碼，不存姓名
  • 一般相機沒有偏光濾鏡，反光會影響紅色區、棕色斑判斷；紫外線色斑與紫質需要 UV 燈拍攝
  • 結果是保養參考，不能取代皮膚科醫師診斷
